v2.4.0

Enhanced AI Context Awareness

Our AI engine now understands multi-file context better than ever. We've introduced a new parsing algorithm that respects import trees more accurately.

Added
  • Added support for multi-file context analysis across directories.
  • New --deep-scan flag for recursive documentation generation.
Fixed
  • Fixed a bug where CLI flags were ignored in generation on Windows.
  • Resolved race condition in async file writing.
Improved
  • Improved response time for large repositories by 40%.

Markdown 2.0 & Custom Templates

We've completely overhauled the markdown generation engine. You can now supply your own Handlebars templates to control exactly how Docly outputs documentation.

Added
  • Custom template support via --template flag.
  • Added 15 new built-in themes for documentation sites.
  • Support for Mermaid.js diagrams in output.
Improved
  • Markdown tables are now auto-formatted for readability.
