Installation

Get started with Docly by installing the CLI globally via your preferred package manager.

Quick Start

Terminal 
npm install -g @docly/cli

Alternatively, you can use Yarn or PNPM if you prefer.

Authentication

Once installed, you'll need to authenticate your machine to access your team's documentation projects. 

docly login --email user@example.com
info
SSO Users If your organization uses SSO, please run docly login --sso instead.

Verification

Verify your installation was successful by checking the version number. 

docly --version
# Output: docly version 2.4.0
