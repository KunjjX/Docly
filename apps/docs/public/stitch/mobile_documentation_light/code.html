Quick Start

Get up and running with Docly in less than 5 minutes. Generate beautiful documentation directly from your CLI.

info

Prerequisite

Docly requires Node.js 18.0 or later. Check your version with node -v.

1 Installation

Install the Docly CLI globally using npm or yarn. This will allow you to run the generator from any project directory. 

# Install via npm
npm install -g @docly/cli

# Or via yarn
yarn global add @docly/cli

2 Initialize Project

Navigate to your project root and initialize Docly. This creates a docly.config.json file. 

cd my-project
docly init
