Changelog

Latest updates and improvements to Docly. We're constantly improving our AI models to help you generate better documentation faster.

Oct 24, 2023 Latest Release
v2.1.0

AI Context Awareness & Faster Generation

This update introduces a major overhaul to our context engine. Docly now understands your project structure better by analyzing imports and dependencies before generating documentation. We've also optimized the inference pipeline.

Figure 1: Context window visualization

  • Added Support for Python virtual environments (`venv`, `pipenv`, `poetry`) auto-detection.
  • Added New CLI flag `--dry-run` to preview changes without writing to disk.
  • Improved Generation speed increased by 40% on large codebases.
  • Fixed Fixed an issue where Markdown tables were sometimes malformed in the output.
Oct 12, 2023
v2.0.5

Stability Improvements & Windows Support

A maintenance release focused on squashing bugs reported by our Windows user base.

  • Fixed Critical: CLI crash on Windows terminals when using PowerShell due to encoding issues.
  • Fixed Path resolution errors for nested directories in monorepos.
  • Improved Better error messages when API rate limits are exceeded.
Sep 28, 2023
v2.0.0

Major Release: Docly Cloud Sync

We are thrilled to announce Docly 2.0! This release introduces Cloud Sync, allowing you to host your documentation directly on Docly's platform with a single command.

Terminal
$ docly deploy --public

> Generating docs...
> Deploying to https://docly.dev/u/project-alpha
✔ Published successfully!
  • Added Cloud Sync: Deploy docs instantly with `docly deploy`.
  • Added Team collaboration features for Enterprise plans.
  • Improved Completely redesigned CLI output with colorful progress bars.
