Introduction

Docly is an AI-powered documentation generator designed to help developers create beautiful, comprehensive documentation for their CLI tools in seconds. By analyzing your codebase, Docly understands your command structure and generates accurate explanations automatically.

info

New Feature Available

We just released support for TypeScript interfaces. Check out the Type Generation guide to learn more.

# Why Docly?

Writing documentation is often neglected in fast-paced development cycles. Docly solves this by integrating directly into your CI/CD pipeline, ensuring your docs are always up-to-date with your latest commit.

  • Zero Config: Works out of the box with popular CLI frameworks like Oclif, Commander, and Yargs.
  • AI-Enhanced: Uses LLMs to generate human-readable descriptions for complex flags.
  • Themes: Choose from beautiful presets or customize with Tailwind CSS.

# Quick Example

Run the following command in your project root to generate a documentation site:

Terminal 
npx docly init

This will create a docly.config.json file and a docs/ folder with your initial site structure.
