# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | ✅ Active support  |
| < 2.0   | ❌ Not supported   |

## Reporting a Vulnerability

We take security seriously. If you discover a security issue, please DO NOT file a public issue.

Instead, send a private report to:

- **Email**: kunjjarsaniya07@gmail.com
- **GitHub**: Use the [Security Advisories](https://github.com/kunjjarsaniya/Docly/security/advisories) page

You should receive a response within 48 hours. If you don't, follow up.

## What to Include

- Type of vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope

- The `docly-cli` npm package
- Generated documentation output
- API key handling in environment variables
- Mermaid diagram rendering pipeline

## Out of Scope

- Third-party dependencies (report to their maintainers)
- The docly.dev marketing website (separate project)

## Disclosure Policy

We follow a 90-day disclosure window. We'll acknowledge your report, work on a fix, and release a patched version before public disclosure.
